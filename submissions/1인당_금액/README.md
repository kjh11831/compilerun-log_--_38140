## 문제 지문

총액 T와 인원 수 N이 주어집니다. 1인당 내야 할 금액(T/N, 내림)을 출력하세요.

[입력] T N
[출력] 1인당 금액(내림)


## 내 정답 코드 (Python)

```python

print(T // N)
```
